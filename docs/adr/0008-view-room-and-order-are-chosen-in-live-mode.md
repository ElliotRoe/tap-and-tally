# View, room and order are chosen in Live Mode, not stored on the Class

A Class used to carry its View, its Room Layout and its Grid View order as settings. We
moved all three into Live Mode, where the teacher switches them mid-class, because the
same class really does meet in different rooms (the library, a lab) and a teacher
reaching for a settings page mid-lesson is a teacher who has stopped teaching. Each Class
quietly reopens the way it was last used, so nothing needs re-picking day to day.

## Consequences

Because any Class can be shown in any Room Layout, an Assignment belongs to a Class *in a
Room Layout*, not to the Class alone. The first time a Class is shown in a room it is
seated A–Z, and each room keeps its own seating. The Menu stays a Class setting, since it
decides what the Class's Reports contain. This supersedes the part of ADR 0007 where a
Class points at one Room Layout. Room Layouts are still shared, not copied.
